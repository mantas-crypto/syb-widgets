# partner-cdn

Snapshot branch with only the live files for surfyogabeer.com/partner (CSS, JS, photos).
jsDelivr refuses to serve from the main branch because the whole repo is over its 50 MB limit,
so the Easol embed block is pinned to a commit on this small branch instead.
Source of truth: pages/partner on main. Do not delete this branch: the live page loads from it.
